## 🚀 Getting Started

### Prerequisites

Make sure you have Python 3 installed on your machine. You can check your installation with:

```bash
python --version
```

### Running the Code

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Roshan-V-R/Python-Coding-Problems.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd Python-Coding-Problems
   ```

3. **Run a specific script:**
   ```bash
   python "First Occurence.py"
   ```
